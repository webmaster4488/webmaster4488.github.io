# Public site

This is the static Cloudflare Pages site for 44jfk.com. The members application is a separate Cloudflare Pages project.

Use the issue's acceptance checklist. Make changes on a branch and link the issue in the pull request. Include checks run and screenshots for visual changes. Review links, static assets, and the door interaction on both mobile and desktop. Preserve the custom domain and the members sign-in link. Leave merging and production deployment to the webmaster.
